# NDC Oslo × GitHub Copilot Workshop

Two hands-on GitHub Copilot labs for [NDC Oslo 2026](https://ndcoslo.com/) (14–18 September 2026, Oslo Spektrum) with Kayla Cinnamon and James Montemagno.

## Tracks

1. **Copilot App** — Move from issue to implementation, review, testing, and merge using the GitHub Copilot app.
2. **Copilot CLI** — Plan, build, parallelize, review, and extend a retro contribution arena from the terminal.

## Getting started

See the [preparation guide](src/content/docs/prepare.md) or the deployed site.

This repository contains only the workshop website. Runnable projects live separately:

- [Tailspin Toys](https://github.com/github-samples/tailspin-toys) for the Copilot App track
- [Mona Mayhem](https://github.com/jamesmontemagno/workshop-mona-mayhem) for the Copilot CLI track

## Development

```bash
npm install
npm run dev
```

## Build and validate

